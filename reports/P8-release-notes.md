# 0.1.0 发行说明

日期：2026-11-14 UTC。仓库：[jide315/uyghur-pos](https://github.com/jide315/uyghur-pos)；发行：[v0.1.0](https://github.com/jide315/uyghur-pos/releases/tag/v0.1.0)。外部用户、独立复现和上游采用暂无。

本候选交付维吾尔语预分词词性标注工具及可核验实验。新增价值是小模型训练／推理实现、统一指标、可定位 OOV 错误、匹配容量的监督与软蒸馏对照、固定三种子和测量稳定性检查。适用于研究与 CPU 原型验证；真实领域需求仍未获外部验证。

候选三种子测试总体均值 90.103%，同容量监督对照 89.406%，Stanza 89.690%。发行权重 C13 按 dev 预先选定。完整恢复轮 C13 CPU p50 2.782 ms，速度比 6.031x，总判定 PASS。只有 PASS 才能使用“达到本项目预设压缩门槛”的表述。

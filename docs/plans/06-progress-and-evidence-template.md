每阶段报告使用以下字段：

```text
阶段编号／名称：
状态：未开始 / 执行中 / 通过 / 未通过 / 证据不足 / 不适用
计划版本：

本阶段目标：

源码版本或源码包 SHA-256：
环境／数据／模型版本：
执行命令、工作目录、退出码与日志路径：
交付文件路径及 SHA-256：
验收条目逐项结论：
实测结果（无结果则写“未测”）：
费用及累计支出：
未通过／证据不足项及影响：
继续 / 返工 / 停止，以及依据：
下一步：
```

不能仅凭写完报告把阶段标成通过；每个硬条件都需要能查到的文件、运行记录或测量结果。“不适用”须说明条件，例如本地完成训练而未使用 AutoDL。

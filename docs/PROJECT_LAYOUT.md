# 本机项目位置

项目统一存放在 `/root/src/uyghur-nlp/`，属于本机 `/root/src/` 项目目录。源码、训练成果、数据、文档、发行包和连接配置均在项目目录内。

| 路径 | 内容 |
| --- | --- |
| `src/uyghur_pos/` | 可安装的模型、训练、评测与推理代码 |
| `scripts/`、`tests/` | 正式实验入口与测试 |
| `docs/`、`reports/` | 方案、执行管理、实验结果、复现与求职说明 |
| `runs/`、`models/` | 15 次训练权重、训练记录与公开预训练资源 |
| `data/`、`artifacts/` | 固定数据、预测、测量与验收证据 |
| `dist/` | 待发布的源码、模型、实验及证据包，附哈希清单 |
| `backups/` | AutoDL 原始完整快照及恢复前发行备份 |
| `credentials/` | 私有连接配置，目录 700、凭据文件 600，不入库 |
| `operations/local/` | 原先位于临时目录的本次任务编排脚本、安装日志与迁移清单，不入库 |

2026-11-14 已将 16 个 `/tmp/uyghur-*` 辅助文件移入 `operations/local/`，逐个校验内容哈希一致。正式源码、权重和已发布前冻结记录没有因归档而改变。

总项目索引仍由系统统一保存在 `/PROJECTS.md`；该文件是全局索引，不作为本项目副本迁移。

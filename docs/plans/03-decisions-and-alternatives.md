# 备选方向与决策记录

记录日期：2026-11-12

补充日期：2026-11-13；主题保持不变，已补齐 [P0–P8 阶段验收](04-phase-goals-and-acceptance.md) 与 [评测协议](05-evaluation-protocol.md)。AutoDL 仅为可选执行环境，目前尚未接入。

## 1. 当前决策

选择文本路线，暂定以轻量词性标注的 CPU 部署为主题。当前只固定文档，尚未进入实现或租卡。

原因：用户明确以求职和开源成果为目的，没有自有数据，只能使用公开资源；母语能力及协作条件尚未确认。优先选择已有标注、评价规则明确、单卡试错成本可控的任务。

这是基于当前条件的工程选择，不代表文本天然优于图片或语音。

## 3. 其他方向的具体机会与限制

### 方言／垂直领域小数据

例子：某地区、某类店铺的自然补货表达，重点观察商品叫法、数量、单位和连读。

可能优势是持续获取并审校真实失败样本。用户目前没有数据入口，不能把这种优势写成现有资源；公开朗读数据也不能代替真实场景验证。

### 最后一公里适配

例子：语音草稿结合每日商品目录；或同一商户、固定版式价目表的商品—价格对应。

价值应以关键字段正确率和人工修改时间衡量。当前没有真实使用方，不作为主线。

### tokenizer、标点与场景评测

例子：公开文本上的标点恢复、字符处理与词级标签对齐；或既有模型在未登录词、长词上的表现。

token 数量下降并不等于任务能力提高。替换预训练模型 tokenizer 还涉及嵌入与训练适配，不作为低成本默认方案。

若研究标点恢复，已有书面标点可以构造任务，但不应把结果当成真实 ASR 字幕效果。

### 母语者协作与本地化流程

例子：建立保留口语／规范书写／无法判定的裁决规范，以及来源、授权、版本记录。

这需要稳定合作，不等于天然壁垒。当前不假定有人可提供持续审校；本地处理也不自动等于满足全部合规要求。

### 图片／OCR

候选题目：维吾尔语文字行识别在模糊、压缩、低分辨率下的鲁棒性。

公开资源入口：[Uyghur OCR SUST/RUST](https://huggingface.co/datasets/anke01/Uyghur_OCR_SUST_RUST)。讨论时该页面有数据与许可标注，但原始来源、真实／合成比例、切分及下载可用性尚未验证，不能视为已完成数据准入。

若未来转向 OCR，先检查字体、源文本、页面和拍摄批次是否跨切分泄漏。受控合成退化上的改善，不能直接宣传为真实拍照 OCR 的改善。

### 语音

公开起点：[THUYG-20](https://us.openslr.org/22/)、[MMS ASR](https://huggingface.co/facebook/mms-1b-all)。

有公开数据不等于没有价值，但音频处理、说话人隔离、转写判断及训练链条更长。目前没有明确语音岗位目标，因此不优先。MMS 模型卡中的非商业许可限制也需要根据具体用途检查。

## 4. 什么不算已证明的贡献

- 支持一种已有工具覆盖的语言。
- 包装一个 API 或演示页面。
- 微调权重但没有强基线与公平评测。
- 用没有任务指标支撑的 tokenizer 压缩率宣称能力提升。
- 将公开语料重复上传当成新数据集。
- 将受控噪声结果外推为真实业务效果。

## 5. 后续会改变路径的未知项

1. 目标岗位：NLP、模型部署、视觉或语音；若目标是视觉／语音岗，需要重新评估任务匹配度。
2. 维吾尔语听读写水平与是否存在稳定母语者合作。
3. 每周可投入工时、精确预算和可租显存。
4. 基线实际资源开销、可用压缩空间与潜在使用者需求。

这些未知项不阻止先保存方案，也不构成已经批准租卡、训练、发布仓库或对外发送消息。
